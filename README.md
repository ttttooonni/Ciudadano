# Ciudadano · Barbate 360º

PWA estática para consultar asuntos públicos de Barbate y sus núcleos con fuentes enlazadas, áreas temáticas y una metodología transparente.

## Publicar con GitHub Pages
1. En GitHub, abre **Settings → Pages**.
2. En **Build and deployment**, elige **Deploy from a branch**.
3. Selecciona la rama `main` y la carpeta `/(root)`; guarda.
4. Espera a que termine el despliegue y comprueba la URL que indique GitHub.

## Archivos
- `index.html`: interfaz, contenido y filtros.
- `manifest.webmanifest`: instalación como PWA.
- `sw.js`: caché básica para uso sin conexión tras la primera carga.
- `icon.svg`: icono de la aplicación.

## Criterios editoriales
- Distinguir propuesta, solicitud, anuncio, financiación, ejecución y finalización.
- Acompañar las afirmaciones relevantes de una fuente original y fecha.
- No tratar una solicitud de subvención como concesión, ni una obra anunciada como obra terminada.
- Las líneas de trabajo que aparecen en la versión inicial son ideas para estudiar, no compromisos aprobados.
- Evitar recoger datos personales innecesarios o inferir preferencias políticas.

## Mantenimiento
Revisar enlaces, fechas y estados antes de cada publicación. La web no sustituye a las fuentes oficiales enlazadas.
